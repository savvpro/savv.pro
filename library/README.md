## How to read these

Each doctrine is a self-contained argument. You don't need to read them in
order — but the four together describe a coherent operating model:

- **Doctrine 01** dismantles the conventional org chart
- **Doctrine 02** explains what replaces feature-thinking
- **Doctrine 03** explains the infrastructure that replaces management
- **Doctrine 04** explains how the work reaches the world

If you only read one, read **Doctrine 03 · The World Model Imperative**. It is
the load-bearing argument that everything else rests on.

## Versioning

These are versioned documents. Significant revisions increment the version
number and add a changelog line at the bottom of the file. Typo fixes do not.

To see all revisions: `git log --follow library/<doctrine-slug>.md`
