# SavvPro — Image Generation Prompts
**savv.pro · v1.1 · May 2026 · 10 images total**

10 self-contained prompts. Each is a single paragraph you can paste directly into an image generator (Imagine.art, Midjourney, Flux, DALL·E, etc.) without any prefix or suffix. Each prompt names its position on the website, its aspect ratio, and the SavvPro design system so the model has full context. Save the output as `public/img/{id}.webp`.

**Budget:**
- 7 × 16:9 cinematic widescreen heroes (one per page-hero / doctrine)
- 1 × 5:4 landscape (homepage "honesty" moment)
- 2 × 4:5 portrait (the two named ecosystem partners on /partners)

## Generation order

1. `hero` first — it sets the tone for everything else. Iterate 4–6 times until right.
2. `doctrine-01` second — second-most-prominent image on the site.
3. The other three doctrines (`doctrine-02`, `doctrine-03`, `doctrine-04`) in one batch using consistent seed and reference image.
4. `partners-hero` and `join-hero` next.
5. `honesty`, `ecosystem-moinc`, `ecosystem-zovox` last.

## File naming & placement

Save each generated image as `public/img/{id}.webp` where `{id}` matches the heading.

```
public/img/hero.webp
public/img/doctrine-01.webp
public/img/doctrine-02.webp
public/img/doctrine-03.webp
public/img/doctrine-04.webp
public/img/partners-hero.webp
public/img/join-hero.webp
public/img/honesty.webp
public/img/ecosystem-moinc.webp
public/img/ecosystem-zovox.webp
```

Once placed, the `ImageSlot` component will be wired to detect and serve them automatically (fallback to the styled placeholder if missing).
